# Audit: parity lookup and migration ledger

Two cards for deciding what a port can keep. The parity data is
`api-comparison/three-core.txt`, generated by `bun run api:compare` from
three.js `src/Three.Core.js` and EASEL `src/index.ts`; its header names the
versions (`@xsyetopz/easel@0.7.0`, `three@0.186.1`).

## Contents

- Parity lookup
- Migration ledger

## Parity lookup

**Definition.** `python3 scripts/parity.py SYMBOL...` prints the ledger rows
for each symbol. Row columns: state, subject, kind, EASEL shape, three.js
shape. States: `=` both, `<` EASEL-only, `>` three-only, `!` shape differs.
The script renames three.js classes as the generator does, folds
`getX`/`setX` into the accessor row, lists EASEL standalone exports for a
three-only static, and summarizes member states for a class. Exit 0 all
found, 1 a symbol has no row, 2 bad usage or missing or malformed ledger.

**Use when.**

- Before porting any three.js member you have not checked this session.

**Do not use when.**

- Taking the row as the whole answer. Known limits:
  - The three.js side covers `Three.Core.js` only: `WebGLRenderer`,
    add-ons (`OrbitControls`, `GLTFLoader`) and `three/webgpu` are absent
    (exit 1 means "not in the ledger", not "absent from three.js"). Check
    `src/index.ts` and the add-on source instead.
  - Fields three.js creates with `Object.defineProperties` (`position`,
    `rotation`, `quaternion`, `scale` on `Object3D`) show `<` although
    both libraries have them.
  - Some subjects have two rows: `Timer` merges three.js `Clock` and
    three.js `Timer`.
  - A `=` row proves the same signature, not the same behavior; see the
    bounding-sphere note in [renamed classes](api-shape.md#renamed-classes).

**Example.**

```text
$ python3 scripts/parity.py Object3D.dispose Color.getHex
# EASEL=@xsyetopz/easel@0.7.0 THREE=three@0.186.1 entry=src/Three.Core.js
# Object3D.dispose -> Node.dispose
> Node.dispose method - instance () => void
! Color.hex accessor instance rw number instance (colorSpace: ...) => number
> Color.hex accessor - instance (hex: number, colorSpace: ...) => Color
```

(Tabs shown as spaces and long shapes shortened.)

Runnable: `scripts/parity.py`, tested by `scripts/test_parity.py`, which
also fails when its rename map drifts from
`scripts/api-comparison/compare.ts`.

**Cost removed.** Guessing whether a member exists; one deterministic
lookup instead of prose tables that go stale with each three.js release.

**Verify.**

1. `python3 scripts/test_parity.py` passes.
1. `python3 scripts/parity.py` with no argument exits 2;
   `python3 scripts/parity.py WebGLRenderer` exits 1.

## Migration ledger

**Definition.** One row per imported three.js symbol and per relied-on
non-default behavior, each with exactly one status:

- `direct`: EASEL export exists and the behavior used is verified.
- `adapt`: the role exists; name, construction, data, result or
  appearance differs (most rows).
- `surface-only`: the class or field exists, but the renderer or subsystem
  that should consume it does not (for example `Scene.environment`, kept
  as data per `CONTRIBUTING.md`).
- `unsupported`: inspected EASEL source shows the behavior is outside the
  CPU Canvas2D contract (shaders, PBR, shadow maps, render targets, XR,
  post-processing).
- `UNKNOWN`: the evidence checked does not settle it; list the files
  checked and the validation needed.

**Use when.**

- Auditing a whole three.js app before or during a port.

**Do not use when.**

- Porting one snippet; apply the cards directly.
- Marking `direct` from a matching name alone, or `unsupported` from a
  missing root export alone.

**Example.**

```text
| three.js import | Use | Evidence | Status | Consequence |
| --- | --- | --- | --- | --- |
| WebGLRenderer | canvas, loop | src/renderers/Renderer.ts | adapt |
  rAF loop, fixed framebuffer size, no pixel ratio |
| MeshStandardMaterial | roughness 0.4 | parity.py: > | unsupported |
  LambertMaterial, lighting look changes |
| TextureLoader | wood.png 512px | src/loaders/TextureLoader.ts | adapt |
  load returns void; image scaled to 128 |
| AnimationMixer | walk clip | parity.py: Animator ! rows | adapt |
  paths lose leading dot |
| GLTFLoader | GLB + Draco | src/loaders/GLTFLoader.ts, _gltf/ |
  UNKNOWN | parse takes JSON plus a caller-supplied binaryChunk; no
  GLB container reader or Draco decoder found; test the real asset |
| EffectComposer, UnrealBloomPass | bloom | not in src/index.ts |
  unsupported | omit or pre-bake glow |
```

Each row is one table line in the real ledger; wrapped here for width.

**Cost removed.** Parity claimed from names, and silent feature loss. The
instrument is the ledger itself: rows without a status or evidence path,
counted with `rg -c '\| (direct|adapt|surface-only|unsupported|UNKNOWN) \|'`
against the number of imports.

**Verify.**

1. Every import found by
   `rg -o "from ['\"]three[^'\"]*['\"]" -r '$0' <src>` has a row.
1. Every `direct` row names a test or oracle that ran.
